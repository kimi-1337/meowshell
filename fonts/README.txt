MeowShell custom fonts
======================

Place .ttf, .otf, .woff, or .woff2 files in this directory and restart
MeowShell. They will appear under Settings -> Appearance -> Fonts. The fonts do
not need to be installed system-wide.

Official free sources:

Interface fonts:
- Inter: https://rsms.me/inter/
- Manrope: https://fonts.google.com/specimen/Manrope

Terminal fonts:
- JetBrains Mono: https://www.jetbrains.com/lp/mono/
- Cascadia Code: https://github.com/microsoft/cascadia-code/releases
- Fira Code: https://github.com/tonsky/FiraCode/releases

Regular and Bold files are usually enough. See README.ru.txt for Russian.

# Contributing

Thanks for helping improve MeowShell.

1. Open an issue before a large behavioral or interface change.
2. Create a focused branch and keep unrelated changes separate.
3. Run `npm ci` and `npm run verify` before opening a pull request.
4. Test terminal startup, local PTY, and any changed SSH/SFTP behavior on the
   Windows architecture you have available.
5. Never commit credentials, private keys, tokens, host inventories, crash dumps,
   or exported user configuration.

By contributing, you agree that your contribution is licensed under
GPL-3.0-only.
